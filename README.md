# Before We Eat

ちゃんと「いただきます」。編者 MINA。

小学生が一皿のお肉から、動物のくらしと食べ方を自分で考えるためのサイトです。肉を食べる立場から、なくせる痛みや無用な暴力を減らすこと、部位に合う料理でおいしく食べきることを大切にします。

## 生成と確認

Node.js 20以降で、リポジトリのルートから実行します。追加のnpmパッケージやブラウザは必要ありません。

```sh
node build.mjs
node verify.mjs
```

`verify.mjs` はPDFのページ数・本文・リンクも検査します。初回は `python -m pip install -r worksheet-requirements.txt` で既存のPDF依存関係を用意してください。

生成先は `dist/` です。公開対象の一覧は `publication.mjs` の原稿データから導きます。現在はトップ1ページと記事・目次86ページ、計87 URLです。404ページと旧URL `top.html` の転送ページは別に生成します。

`verify.mjs` は公開一覧、サイトマップ、メタデータ、内部リンク、別ページを含むアンカー、36皿の材料・工程・画像、30皿の固定URL、79件の記録、写真表示前の構造と3件の個別注意、検索の回帰例を確認します。成功時は `status: passed` を出力します。これは静的検査の結果で、実機や本番画面の確認とは分けて記録します。

## 原稿と編集データ

- `articles.txt` と `articles-v2.txt` は記事原稿です。
- `edition.mjs` は動物・部位・主要料理などの編集データです。
- `plate-recipes.mjs` は追加30皿です。`plate-01` から `plate-30` のURLを並び順で変えません。
- `field-records.json` は79件の現場記録です。`record-1` から `record-79` のアンカーを維持します。
- `search-catalog.mjs` は本文、材料、手順、道具、観察の問い、部位説明などを検索へ反映します。目次は85ページと79記録を検索できます。
- `learning.mjs` は5分・45分の教材、児童用シート、7日記録、買い物の計算例です。
- `cut-atlas.mjs` は30部位の目印と、共有URLに使う固定IDです。精密な解剖図や切り分け線ではありません。
- `editorial-context.mjs` は食卓までの道、公開研究の紹介、説明と資料の対応、更新履歴です。
- `top.template` はトップを生成するための原稿です。`top.html` は既存URLからトップへの転送ページです。配信するトップは `dist/index.html` です。

## 公開時の確認

生成HTMLを直接直すと再生成で戻ります。原稿を直して生成し、静的検査を通したうえで、スマホ幅とPCで主な操作を確認します。ふりがな、大きな文字、動きをひかえる設定、本文だけ読む入口、写真の個別注意を保ってください。公開後は本番URLと公開コミットを照合します。

配信対象は生成物です。原稿・検査スクリプト・編集メモを公開ページとして案内しません。配信方法を変える場合も、既存の記事URLを保ちます。

公開URLは https://djnaoyaman.github.io/beforeweeat/ です。公開前に生成物を検査し、検査済みの生成物をリポジトリルートに反映します。作業の継続記録や公開の検査記録は、公開リポジトリの外で管理します。


## 印刷用PDFの更新

教材3種と7日記録の固定PDFを同梱しています。通常の `node build.mjs` は検証済みPDFをコピーするだけなので、Pythonは不要です。

教材シートの本文を変えたときは、Noto CJKフォントを用意し、`python -m pip install -r worksheet-requirements.txt`、`python generate-worksheets.py`、`node build.mjs` の順で再生成します。各PDFは1ページのA4であることを生成スクリプトが検査します。公開前に4枚を描画し、文字・図・書き込み欄を目視確認してください。PDFでは難しい語をかなに置き換え、ウェブではふりがなを表示します。
