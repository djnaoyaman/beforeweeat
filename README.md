# Before We Eat

ちゃんと「いただきます」。編者 MINA。

`node build.mjs` でトップと記事56本を生成します。`articles.txt` と `articles-v2.txt` は記事原稿、`edition.mjs` は部位・事例・料理の編集データ、`top.html` はトップの原本です。生成ファイルは `dist/` に書き出します。GitHub Pagesでは生成済みファイルを公開ブランチ直下から配信します。

公開URLは https://djnaoyaman.github.io/beforeweeat/ です。出典と事前検査の記録は `LAUNCH.md` を参照してください。
