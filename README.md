# Before We Eat

ちゃんと「いただきます」。編者 MINA。

小学生が一皿のお肉から、動物のくらしと食べ方を自分で考えるためのサイトです。肉を食べる立場から、なくせる痛みや無用な暴力を減らすこと、部位に合う料理でおいしく食べきることを大切にします。

## 生成と確認

Node.js 20以降で、リポジトリのルートから実行します。追加のnpmパッケージやブラウザは必要ありません。

```sh
node build.mjs
node verify.mjs
```

生成先は `dist/` です。公開対象の一覧は `publication.mjs` の原稿データから導きます。現在はトップ1ページと記事・目次86ページ、計87 URLです。404ページは別に生成します。

`verify.mjs` は公開一覧、サイトマップ、メタデータ、内部リンク、別ページを含むアンカー、36皿の材料・工程・画像、30皿の固定URL、79件の記録、写真表示前の構造と3件の個別注意、検索の回帰例を確認します。成功時は `status: passed` を出力します。これは静的検査の結果で、実機や本番画面の確認とは分けて記録します。

## 原稿と編集データ

- `articles.txt` と `articles-v2.txt` は記事原稿です。
- `edition.mjs` は動物・部位・主要料理などの編集データです。
- `plate-recipes.mjs` は追加30皿です。`plate-01` から `plate-30` のURLを並び順で変えません。
- `field-records.json` は79件の現場記録です。`record-1` から `record-79` のアンカーを維持します。
- `search-catalog.mjs` は本文、材料、手順、道具、観察の問い、部位説明などを検索へ反映します。目次は85ページと79記録を検索できます。
- `top.template` はトップを生成するための原稿です。`top.html` は既存URLからトップへの転送ページです。配信するトップは `dist/index.html` です。

## 公開時の確認

生成HTMLを直接直すと再生成で戻ります。原稿を直して生成し、静的検査を通したうえで、スマホ幅とPCで主な操作を確認します。ふりがな、大きな文字、動きをひかえる設定、本文だけ読む入口、写真の個別注意を保ってください。公開後は本番URLと公開コミットを照合します。

配信対象は生成物です。原稿・検査スクリプト・編集メモを公開ページとして案内しません。配信方法を変える場合も、既存の記事URLを保ちます。

公開URLは https://djnaoyaman.github.io/beforeweeat/ です。検査範囲と過去の公開記録は `LAUNCH.md` を参照してください。
